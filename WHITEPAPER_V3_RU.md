# Obscura Codec: Эволюция и Архитектура (Whitepaper)

Данный документ представляет собой технический обзор эволюции криптографического контейнера **Obscura**, от базовых версий до новейшей био-имитационной архитектуры V3.  
*(Примечание: Точные математические формулы, низкоуровневые примитивы исполнения и бинарные файлы ядра V3 засекречены и являются закрытой интеллектуальной собственностью).*

## 1. История Версий и Сравнительный Анализ

Проект прошел три фундаментальные стадии развития, каждая из которых радикально меняла подход к работе с памятью, пропускной способности шифрования и утилизации железа.

| Функция / Метрика | V1: Базовая | V2: Quantum-Neuro | V3: Gorgon Engine (Current) |
| :--- | :--- | :--- | :--- |
| **Управление Памятью** | Чтение файла целиком (RAM = File Size) | Блочное чтение (VFS, чанки по 32 МБ) | **Потоковое (Zero-Copy)**. Динамическое потребление менее 15 МБ (теоретическая масштабируемость до Терабайт). |
| **Параллелизм** | Однопоточный | Однопоточный CPU + GPU-ускорение (Metal) | **Массовый Параллелизм CPU** (Виртуальные потоки) + Подготовка к асинхронному GPU |
| **Криптография** | XOR со сдвигом | Спайковая нейросеть (NeuroRatchet) | **Параллельный NeuroRatchet** с изолированными потоками |
| **Генерация Ключа** | Стандартный HASH | QuantumSpin5D (Хаос и Топология) | Унаследовано от V2 |
| **Скорость (CPU)** | ~15-20 МБ/с | ~40-50 МБ/с | **~320 МБ/с** (Линейно масштабируется от количества ядер) |

## 2. Обзор Технологий и Прототипов

В основе V3 лежат специализированные движки, вдохновленные природными и биологическими механизмами:

### Прототип: "Ouroboros" (Уроборос)
**Суть:** Полное искоренение избыточного потребления оперативной памяти при обработке тяжелых массивов.  
**Как работает:** Вместо загрузки деревьев файлов в оперативную память, Уроборос запускает закольцованный микро-буфер. Поток байт мутирует прямо внутри кольца и мгновенно сбрасывается на диск.  
**Результат:** Позволяет шифровать контейнеры любого объема (предел не ограничен), сохраняя фиксированный профиль памяти всего в несколько мегабайт.

### Прототип: "Gorgon" (Горгона)
**Суть:** Массовый параллелизм без потери криптографической стойкости.  
**Как работает:** Развитие идеи Уробороса. Вместо одной змеи-конвейера Горгона запускает тысячи параллельных микро-задач на виртуальных воркерах. Каждый воркер забирает микро-фрагмент, доводя утилизацию всех ядер процессора до 100%.  
**Результат:** Линейное масштабирование скорости от количества вычислительных ядер.

### Прототип: "Командир Горгоны" (Gorgon Commander)
**Суть:** Синхронизация асинхронных параллельных потоков.  
**Как работает:** Управляет хаосом асинхронных завершений потоков. Каждый входящий блок маркируется монотонным ID. По окончании шифрования Командир восстанавливает хронологию и сшивает блоки в побитово точный поток.  
**Результат:** Идеальное восстановление данных без единой ошибки (Diff = 0).

### Унаследованные Механизмы (V2)
* **NeuroRatchet:** Вместо жестких статических матриц (S-box) используется развивающаяся спайковая нейросеть из 4 узлов. Входящие байты открытого текста служат внешними раздражителями, вызывая пластичность синапсов (STDP) и непрерывно мутируя веса ключа.
* **QuantumSpin5D:** Модуль генерации ключа через нелинейные вращения в пятимерном пространстве хаоса (вектор времени через Золотое Сечение и топология ленты Мёбиуса), полностью исключающий брутфорс-атаки.

## 3. Результаты Нагрузочного Тестирования V3

**Стенд тестирования:**  
Тестирование прототипа проводилось на рабочей станции 9-летней давности — **iMac 27" (2017), Intel Core i5 3.8 GHz, 24GB RAM, Radeon Pro 580**.  
Все бенчмарки выполнялись **исключительно на ядрах центрального процессора (CPU)** без привлечения видеокарты, подтверждая предельную алгоритмическую эффективность архитектуры Горгоны.

* **Тестовый файл:** "Война и Мир" (Текст, 3.20 МБ)
  * *Время шифрования:* 0.01 сек
  * *Время дешифровки:* 0.006 сек
  * *Итог:* Побитово идентичное восстановление (Diff = 0). Эффективная скорость: **~320 МБ/с**.
* **Тестовый файл:** Синтетический бинарный массив (100 МБ)
  * *Время полного цикла:* 0.77 сек
  * *Потребление ОЗУ:* Зафиксировано на отметке ~13 МБ.
